Graflume 차트 유형 갤러리

막대·선·영역·산점도와 서로 다른 mark를 겹친 복합 차트를 하나의 Canvas 기반 엔진으로 렌더링합니다. 각 예제는 Quick API 또는 직렬화 가능한 ChartSpec 0.1을 사용합니다.

막대그래프

범주별 크기를 빠르게 비교합니다.

Graflume.bar()
비교

선그래프

시간에 따른 흐름과 변화를 연결해 보여줍니다.

Graflume.line()
추세

영역그래프

추세와 누적된 규모감을 함께 강조합니다.

Graflume.area()
규모

산점도

두 정량 변수의 관계와 흩어짐을 관찰합니다.

Graflume.scatter()
관계

복합 차트

목표 막대 위에 실적 선과 포인트를 동일 축으로 조합합니다.

Graflume.create({ layers: [...] })
조합
