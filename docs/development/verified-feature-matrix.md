# Verified feature matrix

Generated from the runtime catalogs and `catalog/graflume.features.json`. Do not edit this file directly.

Verified: 2026-08-25 · 44 canonical families · 173 presets/modes · 17 themes.

Status is deliberately conservative: **supported** means an executable and tested contract, **partial** means the current boundary is listed, and **planned/research** is never advertised as runtime support.

## Runtime name-function contracts

- Long-form Area, Bar, and Theme river share the series-stack engine: grouped, stacked, 100-percent, diverging, streamgraph.
- Technical indicators expose 45 named presets plus 2 canonical surfaces (47 total). Exactly 17 are formula-tested computed; 28 are precomputed-required.
- tiled-map is a deprecated embedded-basemap-alias with tile lifecycle and network requests both disabled.
